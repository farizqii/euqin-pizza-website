# Pizza Menu Application

## Description

A pizza menu application that showcases all of the existing pizzas in Euqin's Pizza Restaurant.

## Problem

Euqin's Pizza Restaurant needed a website to showcase all of their pizzas for customers to order.

## Target User

A growing FnB business called Euqin's Pizza Restaurant.

## Features

- Restaurant's Items Showcaser.

## Tech Stack

- Next.js.
- React.
- JavaScript.
- Tailwind CSS.
- Vercel.

## Local Setup

1. Clone repository.
2. Jalankan npm install.
3. Jalankan npx prisma generate.
4. Jalankan npm run dev.
